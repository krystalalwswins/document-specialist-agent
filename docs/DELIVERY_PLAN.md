# 交付计划与当前收口标准

用户确认：最终实现并验证的能力 ≥ 简历承诺；包含 Memory、Evaluation 等增强。最新优先级是先获得可学习的完整项目，SEC-001 超时执行缺陷延期。

## 实施结果

| 批次 | 已实现 | 当前验收口径 |
| --- | --- | --- |
| 1 Retry + Security | 分类重试、工具安全声明、Schema、权限、路径与对象前缀、审计、沙箱会话和资源配额 | 离线验证；用户真实 Docker 报告确认超时停止失败，SEC-001 保持 DEFERRED |
| 2 任务轨迹与异步 | SQLite 任务/步骤/计划/调用/重试/消息落盘，原子队列领取、固定 worker、总时限与调用预算、显式中断恢复 | 真实 SQLite 和并发测试；恢复标记不确定失败，不重放代码 |
| 3 文档与产物 | 输入、任务目录/前缀、CSV/XLSX 解析、元数据、非空/结构要求、有限纠正 | 本地真实 CSV/XLSX 与替身闭环；真实 Docker/S3 烟测入口已提供，结果另验 |
| 4 Memory | 字符预算、完整消息组裁剪、长输出引用、显式脱敏笔记与关键词检索 | 自动化测试；不引入向量数据库 |
| 5 Evaluation + 增强 | usage/耗时/成功率/产物率/重试率，固定评估集；MCP 解析适配和本地服务；SQLite 队列 worker | 离线数据集与协议测试分开记录，不冒充真实模型质量 |

## 可学习性约束

沿用原有接口。优先 Python 标准库 SQLite、ContextVar、线程；文档使用 openpyxl。基础版不需要 Redis、ORM、向量数据库或 MCP 服务器。MCP 为可选依赖。每个模块可沿 [学习指南](LEARNING_GUIDE.md) 找到代码与测试。

明确采用小规模方案：一行 JSON 保存任务快照、关键词检索笔记、数据库 CREATED 状态作为队列。分页、高吞吐队列、分布式租约、多 Agent、恶意多租户隔离和生产部署不纳入学习版。

## 最终仍需核验

- SEC-001：在后续修复中确认代码与延迟副作用可靠停止，保留原烟测断言。
- 真实 Docker/S3：新版任务目录、CSV/XLSX 内容、签名访问、匿名拒绝、URL 过期。
- 真实模型：使用已有固定业务要求执行请求，核验计算和产物内容。
- 环境差异：Windows 符号链接权限问题按 ENV-001 记录，Linux CI 的通过不代表该 Windows 会话具备创建权限。

当前交付是学习版代码和证据，不宣称所有生产风险与外部验证已经完成。最新测试结果见 [验证记录](verification/02_learning_runtime.md)。
